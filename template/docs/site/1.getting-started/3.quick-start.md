## Write the input

::example{input="app/Http/Resources/UserResource.php" output="GET /users/1"}
#input
```php
final class UserResource extends JsonApiResource
{
    protected function toAttributes(Request $request): iterable
    {
        return ['name' => $this->name];
    }
}
```
#output
```json
{
  "data": {
    "type": "user",
    "id": "1",
    "attributes": { "name": "Ada" }
  }
}
```
